# Генератор отчетов по практике

Проект для Codex: подготовка отчета DOCX по исходникам приложения, актуальному примеру и официальным требованиям.

## Что понадобится

Codex с доступом к файлам и терминалу, Python 3.10+ с библиотеками из `requirements.txt`, Microsoft Word на Windows или LibreOffice для экспорта документа. Можно использовать встроенный Python Codex. Для собственного Python установите библиотеки: `python -m pip install -r requirements.txt`.

## Подготовка отчета

1. Откройте папку генератора в Codex. Для новой работы используйте чистую копию.
2. Положите приложение в `project/`, например `project/my-app/`. Добавьте инструкцию запуска и индивидуальное задание файлом или передайте его текст Codex.
3. Положите актуальный пример отчета в `references/current-example/`, желательно DOCX. Прошлые отчеты для стиля добавьте в `references/previous-reports/`, если они есть. При нескольких примерах укажите основной. Официальные требования в `references/official/` оставьте без изменений.
4. Скопируйте `config/student.example.yaml` в `config/student.yaml`, если конфигурации еще нет. Заполните известные сведения о студенте, практике, руководителях и проекте; недостающее Codex уточнит.
5. Отправьте сообщение:

```text
Подготовь отчет по моему проекту по инструкциям AGENTS.md.
Уточни недостающие данные и сохрани итог в output/report.docx.
```

Codex изучит материалы, попробует собрать и запустить приложение, подготовит отчет и проверит документ. Если получить настоящие скриншоты не удастся, останутся подписанные пустые области. Перед сдачей вставьте снимки и попросите повторно проверить отчет.

## Исправление и передача

Для правок положите последнюю версию в `output/report.docx` и укажите изменения и страницы, которые нельзя менять. Итоговые файлы находятся в `output/`, временные материалы — в `temp/`.

Чтобы передать чистый генератор: `python tools/package_generator.py --output output/generator.zip`. Архив не включает ваш проект, персональные данные, отчеты, примеры и скриншоты.

Подробные правила и порядок работы для Codex находятся в `docs/` и `skills/`.
